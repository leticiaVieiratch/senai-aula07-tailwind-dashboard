Catálogo de Classes Atômicas Aplicadas (30+ Requisitadas)

Exigência Atividade 02

Abaixo estão listados os grupos e exemplos práticos das classes Tailwind implementadas nesta página, com seus equivalentes nativos de CSS e aplicações:

1. Cores
  • bg-slate-950 → #020617
  • bg-blue-600 → #2563eb
  • text-emerald-400 → #34d399
  • text-white → #ffffff
2. Tipografia
  • text-3xl → font-size: 1.875rem
  • font-extrabold → font-weight: 800
  • tracking-tight → letter-spacing: -0.025em
  • uppercase → text-transform: uppercase
3. Espaçamentos
  • p-6 / px-4 / py-3 → padding
  • mx-auto → margin-inline: auto
  • gap-4 / gap-8 → gap: 1rem / 2rem
  • space-y-4 → margin-top child
4. Flex & Grid
  • flex / flex-col → display: flex
  • items-center → align-items: center
  • justify-between → justify-content: space-between
  • grid-cols-12 → repeat(12, minmax(0, 1fr))

## 📋 Enunciado da Atividade

1. Crie um projeto que utilize pelo menos **30 classes diferentes do Tailwind CSS**. As classes devem ser utilizadas para definir elementos como cores, tipografia, espaçamentos, dimensões, bordas, posicionamento, flexbox, grid e responsividade.
2. Organize a entrega em um repositório, e documente através de um markdown, contendo prints do código, da aplicação em funcionamento, uma lista das classes utilizadas com suas respectivas funções e o link para o projeto desenvolvido.

---

## 🚀 Como Executar

Abra o arquivo `index.html` em qualquer navegador (Google Chrome, Microsoft Edge, Firefox):
* **Zero Setup:** Utiliza o Tailwind CSS moderno via Play CDN no `<head>`, funcionando diretamente sem etapa de compilação.
